# FunnelFlow Studio

A dependency-free static prototype for building funnel visualization software inspired by tools like Funnelytics. It includes a draggable visual canvas, connected journey steps, KPI cards, editable step metrics, import/export, and local persistence.

## Features

- Add traffic, page, action, email, and conversion steps.
- Drag steps around the funnel canvas.
- Connect steps and automatically calculate conversion rates from visitor counts.
- Edit visitors, cost, revenue, step names, and step types in the inspector.
- Export/import funnel maps as JSON.
- Persist the current map in `localStorage`.

## Run locally

```bash
npm run dev
```

## Build

```bash
npm run build
```
